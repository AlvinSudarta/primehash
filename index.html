PrimeHash

An original password hashing scheme integrating a Sponge Structure with an adaptive Built-In Salting mechanism. No server required — runs entirely in the browser or Node.js.

Quick Start

Get PrimeHash running in under a minute. Choose your preferred delivery method.

Include via jsDelivr 

script src="https://cdn.jsdelivr.net/npm/primehash@latest/dist/primehash.min.js"></script>

Usage 

const hash = PrimeHash.hash("mypassword", 24, 32);
const res  = PrimeHash.verify("mypassword", 24, hash);
console.log(res.valid); // true

Include via unpkg 

script src="https://unpkg.com/primehash@latest/dist/primehash.min.js"></script>

Usage

API Reference

Two functions. That's it.

PrimeHash.hash( password, round, length ) → string

Hashes a password and returns a hex string. Each call produces a different result — a random 64-bit salt is embedded inside the hash output. No separate salt column in your database needed.

ParameterTypeRangeDescription
passwordstringnon-emptyPlaintext password to hash.
roundnumber1 – 24Sponge permutation rounds. Higher = slower & stronger. Recommended: 24.
lengthnumber24 – 99Output in bytes. Hex string = length × 2 chars. Recommended: 32.
 
PrimeHash.verify( password, round, hashedPassword ) → { valid, updateHash }

Verifies a password against a stored hash. When valid, returns a fresh updateHash for hash rotation — replacing the stored hash on each login mitigates credential-stuffing attacks.

Param / ReturnTypeDescription
passwordstringPlaintext password to verify.
roundnumberMust match the round used during hashing.
hashedPasswordstringStored hex hash to verify against.
validbooleantrue if the password matches.
updateHashstring|nullFresh hash for rotation. null when invalid.
